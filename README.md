# Junaid Ali - Portfolio

Personal portfolio of Junaid Ali, Senior Frontend Engineer (React, Next.js, TypeScript).

A single, self-contained `index.html`: no build step, no dependencies, no framework. Open it in any browser or deploy the file to any static host.

## Run locally

Just open `index.html` in a browser. That's it.

## Deploy

- **Vercel:** import this repo, framework preset "Other", then Deploy.
- **Netlify:** drag `index.html` onto app.netlify.com/drop.
- **GitHub Pages:** enable Pages on the `main` branch in repo Settings.
